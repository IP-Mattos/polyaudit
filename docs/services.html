Past the headline numbers

Deeper reads

The browser auditor is free, runs entirely in your own tab, and uses the same method as the command-line tool. It answers the headline question: what did this wallet actually make once the fee and both rebate programs are netted in.

Some wallets need more than that. Era analysis that shows when the money was actually made. Style-shift detection, for a wallet that stopped being the thing it used to be. A side-by-side across several addresses. A cross-check against an independent on-chain reconstruction. That work is done by hand, one wallet at a time, and there is no button for it.

If you need one

Ask, and we work out the shape

Write to polyaudit@gmail.com with the address and what you are trying to decide. If you would rather do it in the open, an issue on the repository works too. Wallet addresses are public data, so put nothing private in an issue. Scope, turnaround and cost get settled before any work starts.

Every method is public in the repo, so none of this is a secret you are paying to unlock. What takes the time is the walk, the cross-checks, and a written verdict you can hold against the record.

If a wallet cannot be reconstructed from public data, the answer is NOT RELIABLE and the reason why, and that costs you nothing. Refusing to certify what cannot be verified is the whole point.

Support

The auditor stays free

It is static, with no account, no server and no tracking, and it is going to stay that way. If it talked you out of copying a wallet whose trading loses money, it already paid for itself. A tip is welcome and changes nothing about what the tool reports.
